# Configuración · submenú y vistas en el chat v1

- Configuración es un disclosure accesible con dos botones: Configuración de
  modelos y Configuración general. Esc/Volver al chat cierran las vistas.
- Las vistas usan el mismo espacio central y estilos. Ocultar/restaurar no borra
  historial, borrador, PNG, campos editados ni reenvía trabajo. Al cambiar de chat
  se vuelve a la conversación. Durante un envío no se abre una vista de ajustes.
- General conserva los controles y contratos diagnostics existentes, incluidos
  revisión/CAS/dirty state. Si ese host no dispone de diagnóstico, explicar límite.
- Modelos reutiliza setup HTML/JS estáticos del binario, inicializado una sola vez
  al abrir. Solo detect/status al navegar; review/confirm/start/stop requieren su
  botón explícito y siguen las guardas del host. No se autoinician modelos.
- No iframe ni relajación de X-Frame-Options DENY. No HTML remoto, eval o scripts
  elegidos por páginas/modelos. La base setup debe ser URL loopback /app/<32hex>/
  del mismo origen, sin usuario/clave/query/hash; nunca bootstrap como base API.
- Conservar cookies HttpOnly y autenticación por ruta; no leerlas ni copiarlas a
  localStorage. Abrir chat tras un cambio de host sigue siendo acción explícita
  de autenticación, no reutilizar una sesión revocada automáticamente.

Rollback: quitar complemento/fragmento y volver al botón general/enlace de modelos
anteriores; sin migración ni eliminación de historial/configuración/marcadores.
