# PreparedWeb · cierre del chat de texto v1

Complemento explícito al frontend congelado; no cambia los seis assets ni el
diseño, el formato version1 del historial o la API OpenAI. Se carga después de
job_history_ui y antes de chat_images_ui, que conserva su idempotencia.

- Validar la única respuesta assistant/texto no vacío y las estructuras que
  consume el renderer antes de modificar historial/DOM. No ejecutar tool calls.
- Metadatos de tiempo ausentes/incorrectos: mostrar — s, no inventar medición.
- HTTP no JSON mantiene clasificación de autenticación/rechazo. Desconexión o
  timeout no confirma que el runtime se haya detenido; no reenvío automático.
- Mensaje restaurado sin respuesta: botón explícito para mover el último turno
  user al compositor. No POST al recuperar, abrir o recargar; el envío posterior
  es manual. No sustituir otro borrador y revertir si falla persistencia.
- Mantener Enter/Shift+Enter/IME, texto seguro, borrador escrito durante la espera,
  exclusión de doble envío y estado accesible en la línea existente.

Pruebas: swarm-app/tests/chat_text_ui.cjs e integración tests/prepared_web.rs.
Fixtures solamente: no certifican Safari, calidad del modelo o cancelación real.
